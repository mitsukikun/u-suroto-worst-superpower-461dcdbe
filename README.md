## The line

> I can control the weather, but only inside a one-inch cube directly above my left shoe.

One line, 87 characters. The power is grand — weather control — shrunk to a cubic inch hovering over one shoe: a tiny personal cloud that can do nothing for anyone, not even its owner. It is genuinely useless rather than a curse, instantly pictured, and specific enough to be unmistakable: a one-inch cube, a left shoe.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, one line, 87 characters).
